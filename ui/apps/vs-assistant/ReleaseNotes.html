Improvements

  • Claude and Codex agents can now be steered mid-turn: sending a follow-up while they're still working injects it into the active turn instead of just queuing it, and multiple queued follow-ups can be reordered or removed before they're sent.
  • Agents with goal-mode support (Claude and Codex) now show a goal chip with status, objective, and progress, with pause, resume, and stop controls.
  • Claude's suggested next prompt now appears directly in an empty composer; press Enter to send it immediately, or Tab, Right Arrow, or click to edit it first.
  • Poolside now supports the standard ACP elicitation protocol, so Claude's AskUserQuestion and Codex's request_user_input and MCP elicitation prompts are answered through the same approval UI as other prompts instead of being silently skipped.
  • Subagent delegations from Claude, Codex, and Pool now render as their own labeled row in the transcript, with status and a provider icon, instead of as a generic tool call.
  • Opening files and viewing diffs is now noticeably faster: syntax highlighting moved off the main thread instead of blocking the UI while a large file is colorized.
  • Enabling ACP protocol logging now works for a brand-new conversation, not just ones that already have an agent session.

Fixes

  • Fixed a bug where sending a follow-up message right as an agent's turn ended could show an error ("unknown steering result") instead of delivering the message.
  • Fixed live steer messages sometimes appearing out of order in the transcript, above tool activity that happened before them.
  • Fixed compaction ("summarizing conversation") status sometimes not being attributed to the right conversation, and made sure it always clears when a turn ends, even after a cancellation or an error.
  • Fixed the elicitation form pushing the prompt box off the bottom of the window, and made its text size match the composer.
  • Fixed a locally discovered model not staying selected after the first message, config changes, or reconnecting.
  • Fixed agent model and mode options going stale until the app was restarted; they now refresh periodically while the app stays open.
  • Fixed inline code formatting breaking apart when edited from the middle of the span.
  • Fixed slash-command text staying grayed out after a space, even once the command menu had closed.
  • Fixed a flicker when a queued prompt containing a code block was shown while waiting to send.
  • Fixed pending permission and elicitation prompts polling the helper every few seconds instead of updating immediately when they change.
  • Fixed the Poolside settings page (Tools > Options) not scrolling, so settings below the visible area couldn't be seen or edited now that the page has grown to hold more of them.
